# POI Chat

React + Vite frontend with shadcn/ui components and Socket.IO. See the [project README](../README.md) for API setup, configuration, hosting, and events.

From this directory, using Node 22.12+ or Node 24:

```bash
npm install
npm run dev
```

The API must be running on port 3000. Open http://localhost:5173 and sign in or register. To test a conversation, use two different browser profiles. Run `npm run lint` and `npm run build` to check the frontend.
